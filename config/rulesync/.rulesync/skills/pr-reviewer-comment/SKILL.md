## ヘルプ・引数

`-h` / `--help` があれば、他の引数より優先して使い方・オプション・既定動作を表示し、PR の取得や投稿を行わず終了する。不明なオプションでも処理を開始せず、このヘルプを表示する。

使い方: `/pr-reviewer-comment <PR の URL または番号> [--submit [APPROVE|REQUEST_CHANGES]]`

| 引数           | 意味                                                                                                                    |
| -------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `-h`, `--help` | ヘルプのみ表示して終了                                                                                                  |
| `--submit`     | 選ばれた指摘と確認済みの本文でレビューを公開。種別を指定する場合は `--submit APPROVE` または `--submit REQUEST_CHANGES` |

既定では指摘候補の提示後に選択を待ち、選んだ指摘を draft にする。「submitして」と明示した場合も、選ばれた指摘と確認済みの本文で公開する。

# pr-reviewer-comment — PR レビューの開始から draft または公開まで

レビュアーとして他人の PR を読み、**指摘候補を出す → ユーザーが選ぶ → draft を作るか公開する**までを進める。
「submitして」（「submit シテ」などの表記も含む）または `--submit` が明示された場合は、選ばれた指摘と確認済みの本文で公開する。通常は draft と本文例を作る。

全体の流れ:

1. PR の情報を集める
2. コードを読み、指摘候補を洗い出して裏を取る
3. 動作確認手順を書く
4. 指摘候補の表と詳細を出す
5. **止まって**ユーザーと壁打ちし、投稿する No を決めてもらう
6. 選ばれた No を draft にするか、明示指定があれば公開する

各手順の詳細は `references/` にある。pr-reviewer-comment-crit skill と共通なので、手順に入るときに該当ファイルを読む。

| 手順 | 読むファイル                 |
| ---- | ---------------------------- |
| 1    | `references/pr-info.md`      |
| 2, 4 | `references/findings.md`     |
| 3    | `references/manual-test.md`  |
| 6    | `references/draft-review.md` |

## 1. PR の情報を集める

`references/pr-info.md` に従う。

## 2. 指摘候補を洗い出し、裏を取る

`references/findings.md` に従う。

## 3. 動作確認手順を書く

`references/manual-test.md` に従う。

## 4. 指摘候補を出す

`references/findings.md` の「出し方」に従い、表と No ごとの詳細を出す。各 No に推奨対応案を添える。

## 5. 止まって、ユーザーに確認する

表と詳細を出したら、**ここで止める**。投稿する No を選んでもらうまで、何も投稿しない。

- 「どの No を投稿しますか？ 区分や文面の相談もどうぞ」と聞く
- 公開指定がある場合は、選んだ指摘の投稿本文とレビュー全体の本文案を提示し、確認済みの文面で 6 に進む
- 壁打ちで指摘が誤りと分かったら、表から外したことを明言する
- 区分や本 PR との関係を変えたら、表を出し直す。推奨対応案が変わったら、該当する No の詳細も出し直す

## 6. レビューを draft または公開として投稿する

`references/draft-review.md` に従う。

## してはいけないこと

- 公開の明示指定なしにレビューを submit しない。既存の PENDING レビューは submit しない
- 他人のブランチへの commit / push、他人のスレッドへの返信、ラベルや状態の変更をしない
- 裏を取っていない候補を表に載せない
