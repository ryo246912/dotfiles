# レビュー段階一覧

| 順序 | skill / 手順                   | 実行条件と役割                                                                                                                                                                                               |
| ---- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | pr-reviewer-brief              | `--brief` 指定時に「説明だけ・動作確認不要」で解説を作る。資料が stack 全体を扱う場合も、指摘は指定 PR の差分に限定                                                                                          |
| 2    | 直接レビュー・教訓照合         | [共通手順](findings.md) の直接確認と教訓照合で差分、関連コード、テスト、過去の指摘と規約を確認                                                                                                               |
| 3    | code-review                    | 同じ PR 差分を読み取り専用で確認できる場合に実行。利用できない場合は直接レビューに代替し、理由を報告                                                                                                         |
| 4    | ponytail-review と専門レビュー | [作者向けの段階一覧](../../pr-author-all-review/references/stages.md) の code-review の次から環境別の追加段階の直前までを順に使う。Ponytail は差分を確認し、専門レビューは関連ファイルが変わった場合だけ実行 |
| 5    | 環境別の追加段階               | 下記の表から対象リポジトリと変更ファイルが一致する行を実行                                                                                                                                                   |
| 6    | pr-reviewer-behavior           | `--behavior` 指定時に候補提示前に一度だけ実行。環境と対象 SHA を控え、別の PR に起因する現象は候補から除く。前提不足なら理由と手動確認手順を残す                                                             |
| 7    | 候補提示・壁打ち・投稿         | 裏を取った候補を提示。ユーザーの選択後に通常は draft を作る。公開は明示指定と本文の確認が必要                                                                                                                |

各段階に同じ比較範囲と該当ファイルを渡す。コードレビューと環境別の追加段階は読み取り専用とし、編集、依存追加、push、投稿を行わない。対象外や未実施の理由を記録し、差分の変化は [共通手順](findings.md) に従って再確認する。

## 環境別の追加段階

このスキルの `SKILL.md` と同じディレクトリに Git 管理外の `work3.md` などを置く。
[作者向けの雛形](../../pr-author-all-review/work3.md.example) と同じ形式で、対象リポジトリと追加レビューを書く。
対象の照合や重複の扱いは [作者向けの手順](../../pr-author-all-review/references/stages.md#環境別の追加段階) に従い、このレビュアー用スキルのディレクトリから設定を読む。
