# PR セキュリティレビューのチェックリスト

| 順序 | 確認項目                   | 確認する内容                                                                                                                                                                   |
| ---- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | 認証・セッション           | ログイン、回復、トークンの発行と検証、期限・失効、Cookie 属性、OAuth/OIDC の発行者・対象・状態の検証。                                                                         |
| 2    | 認可・業務ルール           | サーバー側の操作・オブジェクト・フィールド単位の認可、テナント境界、権限変更、承認、状態遷移、金額等のサーバー側判定、並行更新時の一貫性。                                     |
| 3    | 入出力・ファイル           | クエリのパラメータ化、シェルやテンプレートへの値の受け渡し、逆シリアル化、出力先に合ったエスケープ、アップロードの形式・容量・保存先、パスの境界。                             |
| 4    | 通信・ブラウザ・メッセージ | 外向き通信の宛先とリダイレクトの制約、TLS、CSRF、CORS、CSP、ブラウザ間メッセージの送信元、プロキシとアプリの解釈、Webhook の署名と再処理防止、キュー・RPC の送信元と受信権限。 |
| 5    | データ保護・監査           | 保存時の暗号化と鍵管理、秘密情報の保管、ログ・テレメトリー・エラーからの漏えい、キャッシュ・検索・エクスポート・バックアップの分離、保持と削除、重要操作の監査記録。           |
| 6    | リソース・可用性           | リクエスト・入力・ページング・再試行・並列度の上限、タイムアウト、キュー滞留、ユーザー単位の割当、従量課金経路の上限。                                                         |
| 7    | 依存関係・CI・配布         | 変更された依存と固定されたバージョン、関連する公開アドバイザリ、CI トリガーと信頼境界、ワークフロー権限・秘密情報、配布物・更新の出所と整合性。                                |
| 8    | インフラ・実行環境         | IaC、IAM、ネットワーク公開範囲、コンテナ権限、サービス間の信頼、環境ごとの既定値、デバッグ設定、ポリシー変更時の移行。                                                         |
| 9    | ネイティブ・モバイル・IPC  | メモリと整数の境界、所有権と寿命、FFI、ローカル IPC の呼び出し元確認、deep link・WebView・公開コンポーネント、端末内の秘密情報。                                               |
| 10   | AI・エージェント           | 外部コンテンツと指示の扱い、ツール権限、人による承認、モデル出力の妥当性検査、検索・履歴におけるテナント分離、外部送信するデータの制限。                                       |

確認観点の補足資料として、[Vyber07/cyber-security の公開データセットカード](https://huggingface.co/datasets/Vyber07/cyber-security/blob/bc7a780571cb67d482250649ab573908b9557873/README.md) を参照した。
