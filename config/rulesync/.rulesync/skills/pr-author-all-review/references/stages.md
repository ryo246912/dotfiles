# レビュー段階一覧

| 順序 | 既存 skill                              | 役割                                                                                                                    | 再実行条件                                        |
| ---- | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 1    | pr-author-lessons-review                | 選択 PR の base/head を `--base` / `--head` で渡して教訓を照合。agent-lessons 未設定時は同 skill の規定に従い省略を記録 | 対象差分または base が変わったとき                |
| 2    | code-review                             | 現在の差分のコードレビュー                                                                                              | 対象差分または base が変わったとき                |
| 3    | CodeRabbit CLI（有効時の push 前 hook） | コミット済みの送信対象を既存 hook でレビューする                                                                        | push 時。実行・省略の判定は既存 hook に従う       |
| 4    | pr-author-fix                           | 先行段階の指摘修正・検証・push 後に、PR のレビュー指摘と CI エラーへ対応。ループ時のみ `--auto`                         | head・レビュー・コメント・CI の状態が変わったとき |

段階を追加するときは、順序、skill 名、役割、再実行条件をこの一覧に追加する。追加する skill は、対象 PR / base / head / 未コミット差分のうち何を受け取るかを明示し、指摘・変更・未確認事項を返すものとする。必要な引数と前提ツール、実行不能時の扱いもこのファイルに記載する。既存段階に自動で新しいオプションを渡さず、各 skill に統合ループを持ち込まない。

同じ対象差分に対して pr-author-fix の内部で教訓照合が済んでいる場合、その結果を段階 1 に再利用できる。ただし未コミット差分や base が変わった場合は再実行する。

## 有効時の push 前 CodeRabbit レビュー

CodeRabbit は skill ではなく、既存の `preToolUse` hook（`config/devcontainer/scripts/coderabbit-review.py`）が `git push` の前に実行するレビュー段階。hook が登録され、CLI が利用可能で、対象リポジトリに `.coderabbit.yaml` がある場合のみ動く。無効な環境ではこの段階を適用対象外として記録し、有効化や追加インストールは行わない。

- 既存 hook に実行を任せ、同じレビューを手動で二重実行しない。対象は送信元のコミット済み HEAD で、未コミット差分は対象外
- hook が結果を返して push を止めたら、内容を確認し、妥当な指摘を修正・検証・commit してから通常の push を再実行する。`--loop` ではこの対応も自律的に行い、変更で影響する教訓照合・code-review も再実行する。通常実行は既存の許可範囲に従う
- 同じ送信元 HEAD のレビュー済み判定と省略は既存 hook に従う。省略を新たにレビュー成功したものと扱わず、結果に理由を残す。記録の削除や hook の無効化で push を通さない
- CLI の失敗や部分的なレビューは、push が続行できても未確認範囲を報告する。取得できた指摘は評価する。失敗を完了の根拠にしない

リモートの CodeRabbit bot レビューはこのローカル段階と別であり、push 後は pr-author-fix の段階で CI・他の依頼済みレビューとともに待つ。hook の詳細は `docs/rulesync.md` を参照する。
